# agentic-dev-field-guide — context for an agent session

A public, MIT-licensed guide to AI-assisted development: docs plus templates, no code.
**Personal project** (owner: ip2k). Public: never add names, emails, hostnames, IP
addresses, private project names or account details. Incidents in LESSONS.md stay
anonymized.

- Prices, free tiers and tool versions carry the date they were checked, and link to a
  primary source.
- `START-HERE-FOR-CLAUDE.md` is read by other people's agents: keep its safety rules (ask
  before writing, no hooks without a yes, never handle secrets) intact.
- `.github/workflows/security.yml` is a copy of `templates/github/workflows/security.yml`;
  change both together.
- Each PR adds its notes to `CHANGELOG.md` under `## [Unreleased]`.

Repository hygiene: last read end to end on **2026-11-21** at ~830 lines (first commit).
